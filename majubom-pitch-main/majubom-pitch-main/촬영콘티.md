# 마주봄 시연영상 촬영 콘티 (40초 · 무음 · 2분 피치용)

> 촬영일: 2026-09-16 · 발표: 2026-09-17 · 결과 파일명: **`demo.mp4`** (이 폴더에 넣으면 `pitch.html` 5번 슬라이드가 자동으로 읽음)
> 이야기 한 줄: **낮의 걸음으로 그날 밤 위험을 미리 알고, 밤에 일어나려는 전조에서 간호사가 먼저 도착한다.**

---

## 0. 오늘의 판단 기준 (촬영 시작 전에 합의)

| 상황 | 결정 |
|---|---|
| 센서·대시보드가 30분 안에 정상 동작 | **A안**: 실제 장면 + 대시보드 화면 녹화를 **동시에** 찍는다 |
| USB 끊김 등으로 30분 넘게 안 붙음 | **B안**: 실제 장면만 먼저 찍고, 대시보드 화면은 나중에 시스템을 따로 돌려 녹화한 뒤 편집으로 맞춘다 |
| 그것도 안 됨 | **C안**: 기존 `scenario.mp4`를 쓴다. `pitch.html`이 자동 대체함 |

B안이어도 **오른쪽 화면은 실제 대시보드 녹화**여야 합니다. 그림으로 만든 가짜 UI는 쓰지 않습니다.

## 1. 필요한 것

**사람 (2명 + 촬영 1명)**
- 어르신 역 1명: 걷기 → 눕기 → 걸터앉기 → 일어서려 하기
- 간호사 역 1명: 마지막에 들어와 부축
- 촬영·화면 녹화 담당 1명

**장비**
- 스마트폰 (가로, 1080p 이상, 삼각대 또는 고정). 손으로 들지 않습니다.
- 대시보드 띄울 노트북 + 화면 녹화 (Windows: `Win+G` 게임바 또는 OBS / Mac: `Cmd+Shift+5`)
- 푸시 알림이 오는 폰 1대 (촬영용 폰과 **다른** 폰)
- 센서 실물 (mmWave 보드, ToF, 라즈베리파이) — 마지막 클로즈업용

**환경**
- 침대 있는 실험실. 조명은 **최대한 밝게**. 기존 영상이 어두워서 안 보였습니다. 낮/밤 구분은 조명으로 하지 않고 편집 때 ☀️/🌙 아이콘으로 넣습니다.
- 카메라 위치: 침대 전체 + 걷는 동선 2~3m가 한 프레임에 들어오는 대각선 위치. 프로젝터 화면은 프레임에 안 넣어도 됩니다. 대시보드는 별도 녹화라서요.

---

## 2. 촬영 전 체크 (10분)

1. 센서 켜고 대시보드에서 평면도 위 노란 점이 사람 따라 움직이는지 확인
2. 걸터앉기 → 일어서기에서 위험 뱃지가 실제로 바뀌는지 1회 리허설
3. 푸시 알림이 폰에 실제로 도착하는지 1회 확인
4. 대시보드 창을 **화면 녹화 영역에 꽉 차게** 배치. 브라우저 탭·주소창은 숨김 (F11)
5. 촬영 폰과 노트북 시계 동기화용: 촬영 시작 때 **박수 한 번**을 카메라와 화면 녹화가 둘 다 잡게 (화면 녹화는 마이크 켜서 박수 소리 기록). 편집 때 이걸로 맞춥니다.

## 3. 컷 리스트 (총 40초)

한 테이크로 이어 찍어도 되고, 컷별로 나눠 찍어도 됩니다. **컷별로 나눠 찍는 걸 추천**합니다. 실패해도 그 컷만 다시 찍으면 되니까요.

| # | 초 | 왼쪽 · 실제 장면 (폰 촬영) | 오른쪽 · 대시보드 (화면 녹화) | 편집 때 넣을 자막 |
|---|---|---|---|---|
| 1 | 0~10 | ☀️ 어르신 역이 방 안을 **일부러 느리고 불안정하게** 걷는다. 짧은 보폭, 약간 비틀거림. 카메라 쪽으로 왔다가 돌아간다 | 평면도 점이 따라 움직임. 보행 뱃지 🟢→🟡 | **낮 · 평소보다 불안정한 걸음** |
| 2 | 10~14 | 어르신 역 정지 (프레임 안에 그대로) | 위험 판정 표시 🟠 (야간 이탈 위험 ↑) | **저녁 · 오늘 밤은 위험하다고 미리 판단** |
| 3 | 14~26 | 🌙 침대에 눕는다(3초) → 상체 세워 앉는다(3초) → 침대 가장자리에 걸터앉는다(3초) → 발을 바닥에 딛고 **일어서려 한다, 완전히 서지는 않음**(3초) | 자세 전이 표시, 뱃지 🟠→🔴 | **나오기 전 · 전조 감지** |
| 4 | 26~32 | 폰 화면 클로즈업. 푸시 알림이 **도착하는 순간**을 잡는다 (잠금 화면에 알림 뜨는 장면) | (없음, 폰 화면이 전체) | **간호사에게 즉시 알림** |
| 5 | 32~38 | 간호사 역이 들어와 어르신이 **일어서기 전에** 팔을 잡아 부축한다 | (없음 또는 대시보드 🟢 복귀) | **나오기 전에 곁에** |
| 6 | 38~40 | 센서 실물 클로즈업 (mmWave·ToF·라즈베리파이 나란히) | (없음) | **카메라 없음 · 착용 없음** |

**컷 4 요령**: 알림이 오는 타이밍을 못 맞추면, 컷 3을 찍는 동안 다른 팀원이 폰 화면을 따로 찍어 두면 됩니다. 순서는 편집으로 맞춥니다.

**컷 3 주의**: 실제로 넘어지지 않습니다. "일어서려는 순간"까지만. 넘어지는 장면은 "사후 감지"처럼 보여서 메시지를 깎습니다.

## 5. 간호사 폰 화면 녹화 (시연 페이지 3번째 패널용) — 2026-09-16 추가

시연 페이지(`demo-sync/index.html`)는 `phone.mp4`가 같은 폴더에 있으면 **03 · 간호사 폰** 패널을 자동으로 켜고 현장 영상과 같이 재생한다. 없으면 패널이 숨겨진다.

**찍는 법 (폰 화면 녹화)**
1. 맥에서 MajuBom ToF 서버 실행, 폰 앱(majubom-nurse-app)을 Expo Go로 열고 서버 주소 입력. 폰과 맥이 같은 와이파이.
2. 덱을 한 번 이 주소로 연다 (서버 주소가 브라우저에 저장됨): `pitch.html?phone=http://<맥 IP>:5001#11`
3. 폰에서 **화면 녹화 시작** (iOS: 제어센터 → 화면 기록 / Android: 빠른 설정 → 화면 녹화).
4. 덱 11번 슬라이드에서 Enter로 재생. 영상 장면이 바뀔 때마다 폰이 스스로 바뀐다 (0초 누움 → 7초 주의 → 14초 경고 → 21초 위험 알람).
5. 영상이 끝나면 폰 녹화 중지. 파일을 `demo-sync/phone.mp4`로 넣는다.

**시간 맞추기**
폰 녹화는 재생 버튼보다 먼저 시작되므로 앞부분이 남는다. 폰 영상에서 "주의"로 바뀌는 시각(초)에서 7을 뺀 값이 오프셋이다.
예: 폰 영상 10.2초에 주의로 바뀌면 오프셋 3.2 → 덱을 `pitch.html?phoneOffset=3.2#11` 로 한 번 열면 저장된다.
