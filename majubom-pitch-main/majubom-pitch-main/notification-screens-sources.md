# 10번 슬라이드 화면 출처

- UI: https://github.com/b-hyoung/Majubom/blob/main/site/index.html
- 스타일/렌더링: site/dashboard-assets/dashboard.css, dashboard.js
- 간호사 화면: site/tests/dashboard.spec.cjs의 installMockApi 테스트 fixture로 UI 실행. 실센서 연결/실제 환자 데이터가 아니다. 시연영상과 일치하도록 표시 이름·나이를 김순임 어르신 · 78세로 설정했으며, 발표용 캡처에서는 AI 리포트 확인 버튼과 LIVE 센서 연결 배지를 숨겼다. 센서 수치는 기존 테스트 fixture를 유지한다.
- 리포트 화면: server/reports/2026-08-29.json의 structured_facts를 기존 리포트 모달의 현재_상태, 최근_변화, 보행_변화, 추가_관찰이_필요한_항목, 데이터_신뢰도_설명 필드에 대응시켜 표시했다.
- 원본 JSON은 합성 데이터임을 명시하며 ai_narrative는 null이다. 따라서 AI가 실제로 생성한 리포트 또는 보호자 전용 구현 완료 화면이라는 주장은 하지 않는다.
- 위험점수/신뢰도는 리포트 캡처에서 생성하지 않고 생략했다.
- main 브랜치에서 별도의 보호자 전용 페이지는 확인되지 않았다. 기존 리포트 UI를 '공유 리포트 예시'로 사용한다.
- 두 이미지 모두 실제 저장소 HTML을 브라우저에서 렌더링해 캡처했다. 원본 저장소의 파일은 수정하지 않았다.

## 보호자용 UI 개편

- 현재 슬라이드에는 기존 notification-report.png 대신 guardian-report.png를 사용한다.
- guardian-report.html은 보호자 대상의 새 디자인 예시이며, 기존 저장소에 구현된 보호자 전용 화면으로 표시하지 않는다.
- 2026-08-29 주간 structured_facts의 보행 속도 감소·좌우 흔들림 증가를 쉬운 말로 요약했다. 이전 평균과의 비교이며 '지난주 대비'로 바꾸지 않았다.
- 완료된 간호 조치나 실환자 상태를 새로 만들어 넣지 않았다. 합성 데이터와 진단 대체 불가 안내를 화면에 유지한다.
- 보호자 UI 수치 보강: 속도 -41.8%를 42%로, 흔들림 +133.6%를 134%로 반올림. 속도 0.927→0.539 m/s는 0.93→0.54로 표시했다. '경고' 선택은 UI 등급 표시 예시이며 주간 파일에서 산출한 실제 위험 판정이 아니다. 화면에도 이를 표시한다.
- 사용자 요청으로 '밤에 뒤척임이 심해졌어요' 항목 추가. 확인된 야간 변화 수치에 기반한 문구가 아니며, 화면에서 '야간 상태 표시 예시'로 명시한다.
