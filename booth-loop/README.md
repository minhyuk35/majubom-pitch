# 마주봄 부스 루프 영상 (킨텍스)

`pitch.html`(발표용)은 그대로 두고, 부스에서 틀어놓는 자동재생 버전을 따로 만든 폴더입니다.
폴더째 USB로 옮겨도 동작합니다 (이미지·영상·폰트 모두 `assets/` 안에 포함, 인터넷 불필요).

## 실행
- **`start-booth.bat` 더블클릭** → Chrome(없으면 Edge) 전체화면 키오스크로 바로 재생. 종료는 `Alt+F4`
- 또는 `index.html`을 브라우저로 열고 화면 클릭 / `F` → 전체화면

## 구성 (한 바퀴 약 3분 45초, 끝나면 처음부터 무한 반복)
타이틀 → 문제·개선 → 시스템 구성 → 센서 배치도 → mmWave → ToF → 게이트웨이 → 알고리즘 → 대시보드 → 알림 → 시연영상
- 원본 PPT의 마지막 "감사합니다" 장은 제외
- 시연영상은 `demo-sync`와 같은 3화면 동기화 재생: 현장 영상 · 모니터 확대(대시보드) · 간호사 폰 알림 (`assets/demo/`)
- 화면 하단에 설명 자막이 몇 초마다 바뀌고, 자막에 해당하는 카드만 밝게 강조됨

## 운영 키
| 키 | 동작 |
|---|---|
| `Space` | 일시정지 / 재개 |
| `←` `→` | 이전 / 다음 장면 |
| `Home` | 처음부터 |
| `F` / 클릭 | 전체화면 토글 |

마우스를 2.5초 움직이지 않으면 커서가 숨겨집니다.

## 자막 수정
`index.html` 안의 `var CAPS={...}` 부분에서 문구를 고치면 됩니다.
표시 시간은 글자 수로 자동 계산되고, 특정 자막만 길게 하려면 `{t:'...', d:8}`처럼 초를 지정합니다.
시연영상 자막은 `at:`(영상 재생 초) 기준으로 바뀝니다.
