# 마주봄 부스 루프 영상 (킨텍스)

`pitch.html`(발표용)은 그대로 두고, 부스에서 틀어놓는 자동재생 버전을 따로 만든 폴더입니다.
폴더째 USB로 옮겨도 동작합니다 (이미지·영상·폰트 모두 `assets/` 안에 포함, 인터넷 불필요).

## 실행
- **`start-booth.bat` 더블클릭** → Chrome(없으면 Edge) 전체화면 키오스크로 바로 재생. 종료는 `Alt+F4`
- 또는 `index.html`을 브라우저로 열고 화면 클릭 / `F` → 전체화면

## 구성 (한 바퀴 약 5분 46초, 끝나면 처음부터 무한 반복)
1 타이틀 → 2 기술개발 배경 → 3 제안기술의 차별성 → 4 시스템 구성 → 5 센서 배치 → 6 mmWave 레이더 → 7 ToF 거리 센서 → 8 데이터 처리 장치 → 9 보행 위험 판단 방식 → 10 위험 신호를 확인하는 흐름 → 11 간호사 대시보드 → 12 관찰 결과, 누가 활용하나요? → 13 AI 종합 리포트 → 14 시연 영상 (3화면 동기화)
- 페이지별 화면 내용·자막·타이밍과 발표자용 AI 설명은 **`자막_구성.txt`** 참고
- 13페이지 **AI 종합 리포트**: 환자 기록 → 관련 논문 검색(RAG) → AI 설명 작성(LLM)
- Z-score는 평균과 표준편차로 직접 계산하는 통계 점수로 설명합니다.
- 원본 PPT의 "감사합니다" 장은 제외
- 전주비전대 로고는 `assets/logo-jvision.png` 로 넣으면 자동 표시 (없으면 "전주비전대학교" 글자)

## 운영 키
| 키 | 동작 |
|---|---|
| `Space` | 일시정지 / 재개 |
| `←` `→` | 이전 / 다음 자막 (페이지 끝이면 다음·이전 페이지로) |
| `PageUp` `PageDown` | 이전 / 다음 페이지 통째로 |
| `Home` | 처음부터 |
| `F` / 클릭 | 전체화면 토글 |

마우스를 2.5초 움직이지 않으면 커서가 숨겨집니다.

## 자막 수정
`index.html` 안의 `var CAPS={...}` 부분에서 문구를 고치면 됩니다. 고친 뒤 `자막_구성.txt`도 같이 맞춰 주세요.
표시 시간은 글자 수로 자동 계산되고, 특정 자막만 길게 하려면 `{t:'...', d:8}`처럼 초를 지정합니다.
시연영상 자막은 `at:`(영상 재생 초) 기준으로 바뀝니다.
